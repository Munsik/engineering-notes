# Roadmap

Elastic을 도입하고 운영하는 사람이 실제로 마주치는 순서대로 주제를 나눴습니다.
최상위 분류는 제품 기능이 아니라 실무자가 묻는 질문입니다.

마지막 계획 갱신: 2026-11-27

## 현재 상태

| 구분 | 대상 |
| --- | --- |
| 완료 | 설계 1-1에서 1-5, 수집 2-1에서 2-8, 안정성 운영 3-1에서 3-10, Anomaly Detection 01에서 09. 공개 컬렉션 4개, 글 32편 |
| 진행 중 | 없음 |
| 다음 착수 | 5-1-10(2단계에서 남은 글), 이어서 5-1-11, 5-2 |
| 예정 | 4-1, 4-2, 4-3, 6-1, 6-2 |
| 보류 | 6-3 |
| 남은 재검증 | 3-5에서 3-10의 API를 lab에서 실행 확인(발행 때는 공식 문서와 소스 기준으로만 확인) |

홈의 "다음에 쓸 글" 목록(`src/site-upcoming.mjs`)은 위 "다음 착수"와 "예정"을 같은 순서로 보여 줍니다. 이 표를 바꾸면 그 파일도 같이 바꿉니다.
