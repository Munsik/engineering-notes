# Anomaly Detection Labs

[Anomaly Detection in Production](https://munsik.github.io/engineering-notes/ml/anomaly-detection/) 컬렉션의 실습 자료입니다.

| 경로 | 내용 | 설명 페이지 |
| --- | --- | --- |
| [`hands-on-lab.console`](hands-on-lab.console) | Kibana Dev Tools Console에 붙여 넣어 Lab 순서대로 실행하는 요청 모음 | [08. 실습](https://munsik.github.io/engineering-notes/ml/anomaly-detection/08-hands-on-lab/) |
| [`manufacturing/`](manufacturing/) | 공장 생산망 use case의 Workflow YAML | [09. Use case: 공장 생산망 AIOps](https://munsik.github.io/engineering-notes/ml/anomaly-detection/09-manufacturing-aiops/) |

08 실습은 Kibana 샘플 Web logs(`kibana_sample_data_logs`)만 씁니다.
본문의 결과 수치와 Kibana 화면은 Elastic Cloud Hosted 9.5.5에서 실습을 그대로 돌려서 얻은 실측값입니다. 샘플 데이터는 추가한 날짜를 기준으로 시각이 정해지기 때문에, 직접 돌리면 날짜와 일부 수치가 다르게 나옵니다.

`hands-on-lab.console`은 08 페이지의 코드 블록을 순서대로 모은 것입니다. 페이지와 다르면 페이지가 기준입니다.
